## Лабораторная работа № 4 «Разработка чат-бота. Анализ данных»


Telegram-бот позволяет получать случайные фотографии и искать их по ключевым словам с использованием внешнего API 

## Функционал бота

- `/start` - Приветственное сообщение и описание возможностей.
- `/random_photo` - Получить случайную фотографию.
- `/search_photos <запрос>` - Найти фотографии по ключевому слову.
- `/history` - Посмотреть последние пять запрсов

## Требования

- Python 3.8 или выше
- Доступ к интернету и VPN

## Установка

1.  **Клонируйте репозиторий и перейдите в папку с ботом:**
    ```bash
    git clone https://github.com/huisidun/applied_programming.git
    cd lab4
    ```

2.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

## Для запуска

1.  **Получите токен Telegram-бота:** Обратитесь к [@BotFather](https://t.me/BotFather) в Telegram, создайте нового бота и скопируйте его токен.
2.  **Получите API-ключ фотосервиса:** Зарегистрируйтесь на [Unsplash](https://unsplash.com/developers?ref=buffer-resources) и скопируйте API-ключ.
3.  **Создайте файлы конфигурации:**
    *   Создайте файл `tokenn.py` в корне проекта (`/lab4/tokenn.py`).
    *   Создайте файл `apii.py` в корне проекта (`/lab4/apii.py`).
    *   В `tokenn.py` укажите токен бота:
        ```python
        TOKEN = 'ваш_токен'
        ```
    *   В `apii.py` укажите API-ключ:
        ```python
        UNSPLASH_API = 'ваш_api'
        ```

## Запуск

1.  Запустите основной файл бота:
    ```bash
    python main.py
    ```
2.  Откройте Telegram и найдите вашего бота. Отправьте команду `/start`
